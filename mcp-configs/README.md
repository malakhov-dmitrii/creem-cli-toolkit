# MCP Configs

Ready-to-paste configs for connecting AI agents to your Creem store.

## Claude Code / Claude Desktop

Copy `claude-code.json` content into your `~/.claude/settings.json` (Claude Code) or `claude_desktop_config.json` (Claude Desktop).

## Cursor

Copy `cursor.json` into `.cursor/mcp.json` in your project root.

## Setup

1. Replace `YOUR_CREEM_API_KEY` with your actual API key
2. Use `--server-index 1` for test mode, `--server-index 0` for live
3. Restart your AI client after adding the config

## What you get

22 MCP tools covering products, subscriptions, customers, checkouts, licenses, discounts, and transactions.
